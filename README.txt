=== DartsNow — Setup in 5 minutes ===

The app can't run inside Claude.ai because Claude blocks external connections.
You need to host it somewhere so both you and your friend open the SAME URL.

EASIEST FREE OPTION: GitHub Pages

1. Go to github.com and create a free account
2. Click the "+" top right → "New repository"
3. Name it: dartsnow
4. Tick "Add a README file" → click "Create repository"
5. Click "Add file" → "Upload files"
6. Drag all 4 files (index.html, manifest.json, icon.svg) into the box → click "Commit changes"
7. Click "Settings" tab → scroll to "Pages" in the left menu
8. Under "Source" choose "Deploy from a branch", branch = main, folder = / (root) → Save
9. Wait 1–2 minutes → your app is live at:
   https://YOUR-GITHUB-USERNAME.github.io/dartsnow

Both you and your friend open that link on your phones,
tap Share → "Add to Home Screen" and it installs like a real app!

ALTERNATIVE: netlify.com
- Drag the folder onto netlify.com/drop → instant free URL, no account needed!
